# OpenLumo v0.1 Implementation Plan

**Goal:** Ship the v0.1 core loop: website URL to Brand DNA, proactive drafts with images, an approval board, a calendar and export, all self-hosted with `docker compose up`.

**Architecture:** A pnpm and Turborepo monorepo with two apps (`web`, `worker`) and three packages (`db`, `providers`, `core`). The web app writes rows and enqueues pg-boss jobs. The worker runs every model call through capability interfaces, of which OpenRouter is the first implementation. Progress flows back through `pg_notify` and server-sent events.

**Tech Stack:** Node 22 LTS, TypeScript (strict, ESM), Next.js App Router, Tailwind CSS, shadcn/ui, Better Auth, Drizzle ORM, Postgres 17, pg-boss, Zod 4, cheerio, robots-parser, sharp, satori, fflate, ics, marked, Vitest, Playwright.

**Spec:** `docs/specs/2026-11-03-openlumo-v0.1-design.md`

## Global Constraints

- No code comments anywhere. Names, types and file structure carry the meaning (spec section 10).
- Small modules with one responsibility. One error type (`ProviderError`), one access check (`requireBrandAccess`), one job helper (`defineJob`).
- No new dependency for something a few lines or the platform already does. Every dependency above is the full allowed list; adding one needs a reason in the commit message.
- Package boundaries, enforced with `no-restricted-imports` in `eslint.config.js`:
  - `packages/core` never imports `@openlumo/providers/openrouter`. The one exception is `core/src/models/registry.ts`.
  - `apps/web` never imports `@openlumo/providers`.
  - Only `apps/worker` runs jobs.
- Install the latest stable version of each dependency and pin exact versions in `package.json`.
- Commit messages are plain imperative sentences, such as "Add brand crawler". No prefixes, no trailers.
- Line endings are LF, enforced by `.gitattributes` (`* text=auto eol=lf`).
- Every timestamp is stored as `timestamptz` in UTC. The UI renders it in the browser's time zone.
- Spec values:
  - crawl at most 10 pages including the homepage, 5 redirects, 2 MB per response, 10 s per request
  - 2 parallel generations per brand
  - 3 retry attempts with exponential backoff
  - 3 to 5 campaign ideas
  - top-up keeps 14 days of drafts ahead

## Working Routine

For every task:
1. Follow the steps test first.
2. Run `/simplify` (or the `code-simplifier` agent) on the task's diff and apply only changes that keep behaviour.
3. Re-run the task's tests.
4. Commit.

At the end of each milestone (after Tasks 6, 9, 14 and 21):
1. Run `/graphify . --update`.
2. Read `graphify-out/GRAPH_REPORT.md`. Any edge that crosses a package boundary listed above is a defect. A module that shows up as a god node gets split before the next milestone.
3. Run `/ponytail-review` on the milestone's diff and fix what it finds.

`graphify-out/` is in `.gitignore`.

Known limits that a smaller solution accepts go in the README under "Limitations", never in code.

## Review Focus

1. **Thin websites.** A JavaScript-only site that yields under 200 characters of text should send the brand to the manual form prefilled with name, logo and colors, not fail it. Tested in Task 9.
2. **Messy model output.** JSON wrapped in Markdown fences, or with unknown extra keys, should parse. Missing required fields should get one repair attempt. Tested in Task 3.
3. **Missing image.** If the image model answers with text and no image, the copy must be kept and the image slot must show `invalid_output` with a retry action. Tested in Tasks 4 and 12.
4. **Cyrillic and other non-Latin text.** Overlays must render real glyphs, not boxes. Tested in Task 12 with Ukrainian copy.
5. **Double-clicked Regenerate.** Two identical regenerate requests sent within a second must produce exactly one new version. Tested in Task 13.

**Files:**

API details:
- Base URL is `https://openrouter.ai/api/v1`. Send the headers `Authorization: Bearer`, `HTTP-Referer: https://github.com/openlumo/openlumo` and `X-Title: OpenLumo`.

  - 401 and 403 → `unauthorized`

### Task 7: Safe fetch

**Files:**
- Create: `packages/core/src/crawl/safe-fetch.ts`, `packages/core/src/crawl/private-address.ts`
- Test: `packages/core/test/crawl/safe-fetch.test.ts`

**Interfaces:**
- Produces:
  - `isPrivateAddress(ip: string): boolean`, covering IPv4 `10/8`, `172.16/12`, `192.168/16`, `127/8`, `169.254/16`, `0/8`, `100.64/10`, and IPv6 `::1`, `fc00::/7`, `fe80::/10`, plus IPv4-mapped IPv6.
  - `safeFetch(url: string, options: { allowPrivateHosts: boolean; maxBytes?: number; timeoutMs?: number; maxRedirects?: number }): Promise<{ finalUrl: string; status: number; contentType: string; body: Uint8Array }>`. The defaults are `2_000_000`, `10_000` and `5`.
  - `class UnsafeUrlError extends Error`.

How it works: allow only `http` and `https`. Resolve the hostname with `dns.lookup(host, { all: true })` and reject when any address is private. Fetch with `redirect: 'manual'` and re-check every hop. Stream the body and abort once it passes `maxBytes`.

- [ ] **Step 1:** Write the tests:

  - `ftp://` is rejected
  - `http://localhost` is rejected unless `allowPrivateHosts` is set
  - a redirect to `http://127.0.0.1` from an allowed public stub is rejected, using an injected `lookup`
  - a 3 MB body is truncated with an error
  - a sixth redirect is rejected

  Use a local `node:http` server with `allowPrivateHosts: true` for the positive cases.
